1. SQL Server Stage (Data Ingestion & Dimensional Modeling)
Load the CSV file into a staging table named stg_fmcg_sales using SQL Server Management Studio (SSMS) Import Wizard or BULK INSERT.

A. Dimension Views

SQL
-- Dim_Product
CREATE OR ALTER VIEW vw_Dim_Product AS
SELECT 
    DENSE_RANK() OVER (ORDER BY Category, Brand) AS ProductKey,
    TRIM(Category) AS Category,
    TRIM(Brand) AS Brand
FROM stg_fmcg_sales
GROUP BY Category, Brand;
GO

-- Dim_Store / Dim_Location
CREATE OR ALTER VIEW vw_Dim_Store AS
SELECT 
    DENSE_RANK() OVER (ORDER BY City, Store_Format) AS StoreKey,
    TRIM(City) AS City,
    TRIM(Store_Format) AS Store_Format
FROM stg_fmcg_sales
GROUP BY City, Store_Format;
GO

-- Dim_Customer (Handling NULLs and Demographics)
CREATE OR ALTER VIEW vw_Dim_Customer AS
SELECT 
    DENSE_RANK() OVER (ORDER BY Customer_Gender, Customer_Age, Loyalty_Flag) AS CustomerKey,
    COALESCE(TRIM(Customer_Gender), 'Unknown') AS Gender,
    COALESCE(Customer_Age, -1) AS Age,
    CASE 
        WHEN Customer_Age IS NULL THEN 'Unknown'
        WHEN Customer_Age < 25 THEN 'Under 25'
        WHEN Customer_Age BETWEEN 25 AND 40 THEN '25-40'
        WHEN Customer_Age BETWEEN 41 AND 60 THEN '41-60'
        ELSE '60+'
    END AS Age_Group,
    CASE WHEN Loyalty_Flag = 1 THEN 'Loyal' ELSE 'Standard' END AS Loyalty_Status
FROM stg_fmcg_sales
GROUP BY Customer_Gender, Customer_Age, Loyalty_Flag;
GO
B. Centralized Fact Table View

SQL
CREATE OR ALTER VIEW vw_Fact_Sales AS
SELECT 
    s.Invoice_ID,
    CAST(s.Invoice_Date AS DATETIME) AS Invoice_DateTime,
    CAST(CAST(s.Invoice_Date AS DATETIME) AS DATE) AS DateKey,
    p.ProductKey,
    st.StoreKey,
    c.CustomerKey,
    TRIM(s.Channel) AS Channel,
    TRIM(s.Payment_Mode) AS Payment_Mode,
    s.Units,
    s.Cost_Price,
    s.Selling_Price,
    s.Revenue,
    s.Cost,
    (s.Revenue - s.Cost) AS Profit,
    CASE 
        WHEN s.Revenue = 0 THEN 0 
        ELSE (s.Revenue - s.Cost) / s.Revenue 
    END AS Profit_Margin
FROM stg_fmcg_sales s
LEFT JOIN vw_Dim_Product p 
    ON TRIM(s.Category) = p.Category AND TRIM(s.Brand) = p.Brand
LEFT JOIN vw_Dim_Store st 
    ON TRIM(s.City) = st.City AND TRIM(s.Store_Format) = st.Store_Format
LEFT JOIN vw_Dim_Customer c 
    ON COALESCE(TRIM(s.Customer_Gender), 'Unknown') = c.Gender
    AND COALESCE(s.Customer_Age, -1) = c.Age
    AND (CASE WHEN s.Loyalty_Flag = 1 THEN 'Loyal' ELSE 'Standard' END) = c.Loyalty_Status;
GO

Import Views: Connect Power BI to SQL Server and load vw_Fact_Sales, vw_Dim_Product, vw_Dim_Store, and vw_Dim_Customer.

Generate Dim_Date Table: In Power Query Advanced Editor, create a new blank query named Dim_Date:

Code snippet
let
    StartDate = #date(2024, 1, 1),
    EndDate = #date(2024, 12, 31),
    DayCount = Duration.Days(Duration.From(EndDate - StartDate)) + 1,
    Source = List.Dates(StartDate, DayCount, #duration(1, 0, 0, 0)),
    #"Converted to Table" = Table.FromList(Source, Splitter.SplitByNothing(), {"Date"}, null, ExtraValues.Error),
    #"Changed Type" = Table.TransformColumnTypes(#"Converted to Table",{{"Date", type date}}),
    #"Added Year" = Table.AddColumn(#"Changed Type", "Year", each Date.Year([Date]), Int64.Type),
    #"Added Quarter" = Table.AddColumn(#"Added Year", "Quarter", each "Q" & Text.From(Date.QuarterOfYear([Date])), type text),
    #"Added Month" = Table.AddColumn(#"Added Quarter", "MonthNumber", each Date.Month([Date]), Int64.Type),
    #"Added Month Name" = Table.AddColumn(#"Added Month", "MonthName", each Date.ToText([Date], "MMMM"), type text),

        else "FY" & Text.End(Text.From(Date.Year([Date]) - 1), 2) & "-Q4", type text)
in
    #"Added Fiscal Quarter"
Data Type & Schema Hygiene: Ensure DateKey and Date are set to Date type; numeric keys (ProductKey, StoreKey, CustomerKey) are Int64.Type; and metrics (Revenue, Cost, Profit) are Currency / Decimal Number.

3. Data Modeling Stage
Schema Layout: Arrange tables into a Star Schema with Fact_Sales at the center.

Relationships (1-to-Many, Single Direction):

Dim_Date[Date] → Fact_Sales[DateKey]

Dim_Product[ProductKey] → Fact_Sales[ProductKey]

Dim_Store[StoreKey] → Fact_Sales[StoreKey]

Dim_Customer[CustomerKey] → Fact_Sales[CustomerKey]

Field Hygiene: Mark Dim_Date as the official Date Table. Right-click and Hide all surrogate/foreign keys (ProductKey, StoreKey, CustomerKey, DateKey) in Fact_Sales.

4. DAX Measures
Create a dedicated _Measures table and add the following DAX calculations:

Code snippet
-- Base Financial Measures
Total Revenue = SUM(vw_Fact_Sales[Revenue])

Total Cost = SUM(vw_Fact_Sales[Cost])

Total Profit = [Total Revenue] - [Total Cost]

Profit Margin % = DIVIDE([Total Profit], [Total Revenue], 0)

Total Units Sold = SUM(vw_Fact_Sales[Units])

-- Transactional & Customer Metrics
Average Order Value = AVERAGEX(VALUES(vw_Fact_Sales[Invoice_ID]), [Total Revenue])

Total Transactions = DISTINCTCOUNT(vw_Fact_Sales[Invoice_ID])

-- Time Intelligence
Sales YTD = CALCULATE([Total Revenue], DATESYTD(Dim_Date[Date]))

Profit YTD = CALCULATE([Total Profit], DATESYTD(Dim_Date[Date]))
