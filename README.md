Overview
This project provides actionable business insights by processing raw sales transaction data into interactive visual dashboards and automated reports. It helps sales teams, management, and analysts monitor KPIs, spot growth opportunities, and optimize inventory and strategy.

Key Features
Interactive Dashboards: Real-time visibility into Monthly Recurring Revenue (MRR), total sales, average order value (AOV), and profit margins.

Customer Segmentation: RFM (Recency, Frequency, Monetary) analysis to categorize customers into distinct tiers (e.g., Champions, At-Risk, Loyal).

Regional & Product Breakdown: Heatmaps and performance charts displaying top-performing sales regions and product lines.

Sales Forecasting: Predictive analysis to estimate future sales trends based on historical data.

Automated Data Pipeline: Automated cleaning, ETL (Extract, Transform, Load), and modeling steps for seamless data ingestion.
